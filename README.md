# Invent a Word We Need

make.fun bounty entry: coin one new English word and define it in a single
clear line (at most 140 characters).

The program `main.ts` (pure Node.js standard library, no dependencies) writes
the entry to `/output/entry.txt`:

> Ghostdraft — a message you typed, deleted, and never sent, though it said exactly what you meant.

Run it with Node 22.18 or later: `node main.ts`
